# Legado书源制作实践与常见问题

## 一、书源制作最佳实践

### 1.1 制作流程建议

```
Step 1: 分析目标网站
  - 确定网站结构（静态/动态）
  - 确定编码格式（UTF-8/GBK）
  - 确定反爬机制

Step 2: 从搜索开始
  - 先编写搜索规则
  - 确保能搜出结果
  - 验证书籍列表、书名、作者、详情地址

Step 3: 完善详情页
  - 测试详情页解析
  - 确保书名、作者、简介、封面正确
  - 确保目录地址正确

Step 4: 编写目录规则
  - 确保章节列表完整
  - 确保章节名称、链接正确
  - 处理翻页（如有）

Step 5: 编写正文规则
  - 确保正文内容完整
  - 添加正文净化规则
  - 处理分页（如有）

Step 6: 全面测试
  - 搜索测试
  - 详情测试
  - 目录测试
  - 正文测试
```

### 1.2 调试技巧

| 问题 | 调试方法 |
|:---|:---|
| 规则不生效 | 在浏览器开发者工具中验证选择器 |
| 提取内容为空 | 检查选择器是否匹配，检查是否有动态加载 |
| 内容乱码 | 检查charset设置 |
| 部分内容缺失 | 检查是否有JavaScript动态渲染 |
| 图片不显示 | 检查图片URL是否完整，检查Referer |

### 1.3 性能优化

1. **减少请求次数**：合并规则，避免多次请求同一页面
2. **使用并发控制**：设置合理的并发率，避免被封IP
3. **精简正则表达式**：复杂的正则会降低解析速度
4. **避免不必要的JS**：JS执行较慢，能用CSS/XPath就不用JS

## 二、常见问题与解决方案

### 2.1 搜索相关问题

**Q: 搜索返回空结果**
- 检查搜索地址是否正确
- 检查列表规则是否能匹配到元素
- 检查是否有编码问题（GBK网站需要设置charset）
- 检查是否需要特殊请求头（User-Agent等）

**Q: 搜索结果只有部分字段**
- 检查各字段的选择器是否正确
- 检查是否有多个匹配，使用了`||`只取第一个

### 2.2 详情页相关问题

**Q: 详情页信息不全**
- 检查详情地址是否正确提取
- 检查详情页规则是否正确
- 检查是否有预处理规则覆盖了字段

**Q: 封面图片不显示**
- 检查封面URL是否完整（相对路径需要补全）
- 检查是否有防盗链（需要设置Referer）

### 2.3 目录相关问题

**Q: 目录为空**
- 检查目录地址是否正确
- 检查章节列表规则
- 检查是否有反爬机制（需要Cookie）

**Q: 章节顺序错乱**
- 使用`-`前缀倒置列表
- 检查网站本身是否有排序问题

**Q: 章节重复**
- 使用标题处理去重
- 检查是否有分页导致重复

### 2.4 正文相关问题

**Q: 正文乱码**
- 检查页面编码
- 在搜索地址中添加charset参数

**Q: 正文缺字漏字**
- 关闭净化规则测试
- 检查净化规则是否误杀
- 检查是否有字体加密

**Q: 正文有广告**
- 添加替换规则净化
- 使用正则表达式过滤

**Q: 图片不显示**
- 检查图片URL
- 添加图片Referer
- 检查是否有图片加密

### 2.5 订阅源相关问题

**Q: 订阅源显示为空**
- 检查sourceUrl是否可访问
- 检查ruleArticles是否匹配
- 检查是否为标准RSS（不需要ruleArticles）

**Q: 文章打不开**
- 检查ruleLink是否正确
- 检查是否需要特殊请求头

## 三、高级技巧

### 3.1 处理动态加载

对于需要JavaScript渲染的页面：
```json
{
  "searchUrl": "/search?q={{key}},{\n    \"webView\": true\n  }"
}
```

### 3.2 处理登录验证

```json
{
  "loginUrl": "https://example.com/login",
  "ruleSearch": {
    // 使用CookieJar保持登录状态
  }
}
```

### 3.3 处理加密内容

```javascript
// 在正文规则中使用JS解密
<js>
  var encrypted = result;
  var decrypted = customDecrypt(encrypted);
  decrypted;
</js>
```

### 3.4 多源合并

使用`&&`合并多个规则的结果：
```
@css:.content1@text&&@css:.content2@text
```
